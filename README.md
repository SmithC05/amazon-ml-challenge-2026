# Amazon ML Challenge 2026 - Business Entity Resolution

This repository contains the team solution for the Amazon ML Challenge 2026. The objective is to match business entities from a reference source (Source 1) against noisy records in other sources (Source 2 and Source 3).

## Matching Pipeline (Member 3)

The matching pipeline takes candidate pairs generated by the blocking stage, extracts pair-level similarity features, and applies a Logistic Regression model to identify true matches.

### How to Train
Assuming `output/training_pairs_baseline.tsv` is available:
```bash
python src/train.py
```
This produces the trained model (`models/matcher.pkl`) and its configuration (`models/model_config.json`).

### How to Run Prediction
Assuming test data is in `dataset/test` and candidate pairs are in `output/candidate_pairs.tsv`:
```bash
python src/predict.py
```
This generates the final `output/matching_results.tsv`.

### How to Validate
Run the validation script to ensure the output format is correct before submission:
```bash
python3 utils/validate_submission.py \
  --matching output/matching_results.tsv \
  --candidate output/candidate_pairs.tsv \
  --test-dir dataset/test
```
